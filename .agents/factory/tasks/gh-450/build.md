# Build: gh-450, per-table horizontal scroll wrapper for markdown tables

## Summary
I implemented plan.md as a single group. `MarkdownContent` now wraps every markdown table in its own scroll container: `div.my-3.max-w-full.min-w-0.overflow-x-auto[data-markdown-table-scroll]`.
- Base renderer: the wrapper is placed directly around the table.
- Copyable renderer: the wrapper sits inside `CopyableSnippet`, between the `relative` snippet div and the `<table>`.
- The copy overlay stays a sibling of the wrapper. It is not inside it, so it does not scroll with the table.
- The vertical margin `my-3` moved from the table to the wrapper.

I wrote the regression tests first and they failed before the fix (`reproduce`). They pass after it (`regression_test`).

All four frontend checks pass, and the tracked static bundle was rebuilt with Bun 1.4.4. I checked every surface manually in a real browser on a scratch server.
