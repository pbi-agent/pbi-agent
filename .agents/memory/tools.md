# Tools and tool runtime

Migrated from `MEMORY.md` on 2026-11-07; entries predate verification tags.

- Read/search: no dedicated text read/search tools (issue #382 removed `explore_workspace` + `codetool-explore`); model uses `shell`. Images: `read_image` `{path}` → metadata + `ImageAttachment` via `media.load_workspace_image`; `allowed_tools` group `read-image` (aliases `read`, `read_image` via `normalize_tool_categories`). Intentionally NOT workspace-confined (user decision 2026-11-10: must read outside workspace); size checked via stat before read. Skill catalog gated on `shell` (warns when scoped skills lack shell). `read_web_url` group = `web`. [verified 2026-11-10]
- Shell: required `intent` (3-8 words) on fg/bg start (bg actions exempt). `timeout_ms` removed (no alias; rejected with an error naming `yield_time_ms`): `yield_time_ms` (default 30s, max 5m) — a still-running fg command is handed to the background manager (`BackgroundTaskManager.adopt`) instead of killed; killed only where no manager exists. Fg stdin is DEVNULL. `tty: true` (POSIX only; Windows returns an error) runs under a PTY with the slave as controlling terminal (`preexec_fn` TIOCSCTTY) so Ctrl-C reaches the command; TERM=dumb; output ANSI-stripped. `codetool-shell` compresses streams before 12k/stream bounds. [verified 2026-11-24]
- Shell raw output (#383): when a stream is truncated (12k) or `codetool-shell` compression is lossy (`_is_lossy_compression` ignores whitespace + ANSI), full raw stdout/stderr → `~/.pbi-agent/shell-output/shell-output-<uuid>.log` (dir 0700, file 0600) via `tools/raw_output.py`; payload adds `*_compressed`/`*_truncated`, `raw_output_path`, `notice` (UI only; the model sees one `[compressed; truncated; full: <path>]` tag line). Background: `background_tasks.background_output_payload` writes the file only after finish, cached on `task.raw_output_path`; running → notice only; `*_tail_dropped` (64k tail loss) separate from `*_truncated`; `manager.output()` keys unchanged (web API contract). Purge >24h in daily `run_startup_maintenance` only. Test trap: faking `shell_tool.subprocess.run` also fakes codetool-shell's Rust backend → test real compression via `_build_output_payload`; autouse conftest patches `raw_output.raw_output_dir`. [verified 2026-11-10]
- Background tasks: `background_task` actions list|status|output|input|kill; `output`/`input`/finish message return only unseen output (per-task stdout/stderr cursors, `[N earlier chars already shown]`), `from_start` re-reads; `input` needs a `tty` task, waits `wait_ms` (default 1s) and returns once output settles 300ms. Streams use `tools/stream_buffer.StreamBuffer` (first+last 128k chars; `*_middle_dropped`). Available everywhere: web chat (follow-up steer/idle auto-wake, cap 5) and, via `agent/session/background.run_background_tasks`, `run_single_turn` (CLI run, board, channels) and sub-agents (`own=True`): results injected at tool checkpoints, end-of-turn wait + wake (cap 5, sub-agent deadline), tasks killed at run end. Web panel shows only the main session's tasks. A shell leaving a child holding the PTY/pipes keeps the task running until output closes. [verified 2026-11-24]
- `allowed_tools`: groups `read-image`, `write`, `web`, `sub-agent`, `shell`; CLI `--allowed-tools`, frontmatter `allowed_tools`. Native search requires `web`; empty list disables configurable built-ins. Command-only `ask-user` → runtime `ask_user`; stripped from sub-agents.
- Patching: OpenAI/ChatGPT `apply_patch` = Codex freeform V4A `custom_tool_call`, exact Lark grammar + local validation; reject empty `Update File`/move-only hunks. Other providers use `replace_in_file`/`write_file`.
- MCP lifecycle: SDK HTTP client owned by AsyncExitStack (`http_client=`); per-connection owner tasks; thread worker uses asyncio.Queue + call_soon_threadsafe (never blocking queue.get in executor).
- Model-facing tool output (2026-11-24): `tools/model_output.py` renders plain text for every provider (no `{"ok","result"}` JSON): shell `exit N[ · Xs]` header (time only ≥1s), stdout, `[stderr]` block if non-empty, one `[...]` tag line; errors `error <type>: msg`; generic dicts as `key: value` (empty skipped, nested compact JSON). `ToolSpec.render_output` overrides per tool. `ToolResult.output` = model text (renamed from `output_json`), `ToolResult.payload` = structured envelope for display/hooks; traces store the model text so replay matches live. Hooks: `tool_response` = model text, `tool_result` = envelope. User rule: prefer the most token-efficient option. [verified 2026-11-24]
- `ToolContext.background_handoff=False` (web user `!` shell commands) kills at `yield_time_ms` instead of handing off to the model's background tasks. Simple `tty` commands (no shell syntax chars) are `exec`ed only when `command -v <first word>` resolves to a path (builtins/functions/aliases run unchanged); foreground `tty` output goes through `clean_tty_text` too. Timeline cards parse the background result header line, so keep `render_background_result`'s `<status>[ · dur][ — intent]` first line and `SessionTimeline.parseBackgroundResult` in sync. Shell card/display metadata key is `yield_time_ms`. [verified 2026-11-25]
