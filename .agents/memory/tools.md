# Tools and tool runtime

Migrated from `MEMORY.md` on 2026-11-07; entries predate verification tags.

- Read/search: no dedicated text read/search tools (issue #382 removed `explore_workspace` + `codetool-explore`); model uses `shell`. Images: `read_image` `{path}` → metadata + `ImageAttachment` via `media.load_workspace_image`; `allowed_tools` group `read-image` (aliases `read`, `read_image` via `normalize_tool_categories`). Intentionally NOT workspace-confined (user decision 2026-11-10: must read outside workspace); size checked via stat before read. Skill catalog gated on `shell` (warns when scoped skills lack shell). `read_web_url` group = `web`. [verified 2026-11-10]
- Shell: required `intent` (3-8 words) on fg/bg start (bg actions exempt); shown in shell card title, work-step subtitle, bg panel, bg-result label. `codetool-shell` compresses streams before 12k/stream bounds; `compression=false` bypasses; non-bool rejected. Interruptible process groups/bounded cleanup; Stop keeps history; model interrupt targets sub-agent owner + provider call id.
- Shell raw output (#383): when a stream is truncated (12k) or `codetool-shell` compression is lossy (`_is_lossy_compression` ignores whitespace + ANSI), full raw stdout/stderr → `~/.pbi-agent/shell-output/shell-output-<uuid>.log` (dir 0700, file 0600) via `tools/raw_output.py`; payload adds `*_compressed`/`*_truncated`, `raw_output_path`, `notice`. Background: `background_tasks.background_output_payload` writes the file only after finish, cached on `task.raw_output_path`; running → notice only; `*_tail_dropped` (64k tail loss) separate from `*_truncated`; `manager.output()` keys unchanged (web API contract). Purge >24h in daily `run_startup_maintenance` only. Test trap: faking `shell_tool.subprocess.run` also fakes codetool-shell's Rust backend → test real compression via `_build_output_payload`; autouse conftest patches `raw_output.raw_output_dir`. [verified 2026-11-10]
- Background shell: `run_in_background`/`background_timeout_ms` (default 30m, max 2h)/`background_action` status|output|kill + `task_id`; `tools/background_tasks.py` `BackgroundTaskManager` (4 concurrent, 64k tails). Web-only (`WebDisplay.background_task_manager`); sub-agents rejected; CLI unsupported. Finish → `QueuedFollowUpInput(kind="background_result")` steer or idle auto-wake, cap 5 consecutive wakes (reset on user input). Session end kills; not persisted across restart. UI: right `BackgroundTasksPanel` (topbar toggle, shares `sidePanel` with explorer, main sessions only), `<background_task_result>` rows coalesce as "Background task" work steps; output dialog `task-form-dialog`.
- `allowed_tools`: groups `read-image`, `write`, `web`, `sub-agent`, `shell`; CLI `--allowed-tools`, frontmatter `allowed_tools`. Native search requires `web`; empty list disables configurable built-ins. Command-only `ask-user` → runtime `ask_user`; stripped from sub-agents.
- Patching: OpenAI/ChatGPT `apply_patch` = Codex freeform V4A `custom_tool_call`, exact Lark grammar + local validation; reject empty `Update File`/move-only hunks. Other providers use `replace_in_file`/`write_file`.
- MCP lifecycle: SDK HTTP client owned by AsyncExitStack (`http_client=`); per-connection owner tasks; thread worker uses asyncio.Queue + call_soon_threadsafe (never blocking queue.get in executor).
