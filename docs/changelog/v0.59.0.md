# v0.59.0

**Release date:** 2026-11-13

## Added

- A **TODO** panel in the session topbar (`Alt+Shift+T`) shows the workspace's `TODO.md` files as formatted markdown next to the chat, like the Files, Background tasks, and Terminal panels. It has one tab per `TODO.md`, status icons for done, pending, in-progress (`[>]`), blocked (`[!]`), and dropped (`[-]`) items, and refreshes live while the agent works ([#424](https://github.com/pbi-agent/pbi-agent/pull/424)).
- The TODO panel's status counts act as filters: click a count to show only those items, click it again to show everything ([#424](https://github.com/pbi-agent/pbi-agent/pull/424)).
