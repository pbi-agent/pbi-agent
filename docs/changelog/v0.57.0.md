# v0.57.0

**Release date:** 2026-11-13

## Added

- Kits: `pbi-agent kits add [source] [--kit NAME] [--list] [--force]` copies a packaged set of skills, commands, sub-agents, MCP servers, and instructions into the workspace, by default from the official [pbi-agent/kits](https://github.com/pbi-agent/kits) catalog ([#417](https://github.com/pbi-agent/pbi-agent/pull/417)).
- Run details open as a nested trace timeline: the run, its model and tool calls, and sub-agent runs nested under the call that started them, each with a type badge, duration, and a waterfall bar ([#418](https://github.com/pbi-agent/pbi-agent/pull/418)).
- With the sidebar collapsed, the session topbar shows the workspace and session title; clipped session titles show the full title in a tooltip ([#416](https://github.com/pbi-agent/pbi-agent/pull/416)).

## Changed

- Run details load faster for large runs: request and response payloads are fetched only when a row is opened ([#418](https://github.com/pbi-agent/pbi-agent/pull/418)).
- Work still in progress, such as a model call that has not returned or a running sub-agent, is visible in run details while the run is active ([#418](https://github.com/pbi-agent/pbi-agent/pull/418)).

## Fixed

- Badge text is vertically centered across the web UI ([#415](https://github.com/pbi-agent/pbi-agent/pull/415)).
- The session topbar no longer overlaps its controls when the files, tasks, or terminal panel is open ([#416](https://github.com/pbi-agent/pbi-agent/pull/416)).

## Internal

- The web terminal tests now also run on Windows in CI ([#414](https://github.com/pbi-agent/pbi-agent/pull/414)).
