# v0.32.0

**Release date:** 2026-09-12

## Added

- Added an opt-in script to prepare existing session databases for local-shell provenance tracking, with a SQLite-safe backup before changes. Historical records remain unclassified; the script never runs automatically ([457c9148](https://github.com/pbi-agent/pbi-agent/commit/457c9148a83ed2056f6d8ccfa0958f3ab080f4f7)).

## Changed

- Renamed the running shell tool's “Stop command” button to “Interrupt” to clarify that it stops the command rather than the assistant turn ([8a8e3e95](https://github.com/pbi-agent/pbi-agent/commit/8a8e3e952967d5903e4e00c2df258c22fcc175ce)).

## Fixed

- Recover once from ChatGPT's code-less HTTP 400 `Invalid previous_response_id` error by replaying the full current-turn context, including reasoning, tool calls, and completed results, without rerunning tools. Successful recovery resumes normal response-ID continuation ([d8840418](https://github.com/pbi-agent/pbi-agent/commit/d884041875f88526a935082314c9d416dd580b65)).
- Preserve failed user turns and restore unfinished prompts, intermediate responses, and completed tool exchanges when reopening a saved session, even when completed-turn tool history is disabled. Replay respects checkpoint ordering, retries, forks, attachments, and compaction boundaries ([9df5d6f5](https://github.com/pbi-agent/pbi-agent/commit/9df5d6f5850f1e41a7d09a569b069bce8b7367b0)).
- Keep direct UI shell commands and their output out of model context, compaction, sub-agent snapshots, and prompt enhancement using explicit persisted provenance, while retaining visible history and ordinary bang-prefixed prompts ([457c9148](https://github.com/pbi-agent/pbi-agent/commit/457c9148a83ed2056f6d8ccfa0958f3ab080f4f7)).
