# v0.45.0

**Release date:** 2026-11-06

## Added

- Shell tool calls now carry a short required `intent`, shown on shell cards, work-step subtitles, background task rows, and background result steps ([72c847e](https://github.com/pbi-agent/pbi-agent/commit/72c847e3)).
- The collapsed "Working" header shows the latest tool intent next to tool counts and duration, with an animated transition between steps; it stays faded on finished runs ([72c847e](https://github.com/pbi-agent/pbi-agent/commit/72c847e3)).

## Fixed

- Direct `!command` shell input in web sessions keeps working with the new required shell intent ([72c847e](https://github.com/pbi-agent/pbi-agent/commit/72c847e3)).

## Internal

- Enabled additional Ruff lint rules (`I`, `UP`, `B`, `RUF`, `PLW1510`) and applied the resulting fixes ([5916851](https://github.com/pbi-agent/pbi-agent/commit/5916851c)).
