# v0.56.0

**Release date:** 2026-11-12

## Changed

- Closing a web terminal on Windows now also stops the programs started inside it ([#412](https://github.com/pbi-agent/pbi-agent/pull/412)).
- With a POSIX shell on Windows (for example Git Bash set through `PBI_AGENT_SHELL_EXECUTABLE`), the web terminal starts it interactively and sources `PBI_AGENT_SHELL_BOOTSTRAP` ([#412](https://github.com/pbi-agent/pbi-agent/pull/412)).

## Fixed

- The web terminal tab accepts typing on Windows: the shell now runs in a real pseudo-console (ConPTY, through the new Windows-only `pywinpty` dependency), so keystrokes are echoed and interactive prompts work ([#412](https://github.com/pbi-agent/pbi-agent/pull/412)).
- A shell that cannot be started is reported in the terminal tab instead of leaving a dead connection ([#412](https://github.com/pbi-agent/pbi-agent/pull/412)).
