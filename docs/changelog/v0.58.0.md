# v0.58.0

**Release date:** 2026-11-13

## Added

- On-device speech-to-text: choose **On this device (Parakeet v3)** in Speech-to-text settings to dictate without a provider or API key. The model (about 515 MB, 25 European languages) downloads once with a progress bar and runs on the CPU on Linux, macOS, and Windows ([#422](https://github.com/pbi-agent/pbi-agent/pull/422)).
- Picking a skill's `SKILL.md` from the composer's `@` file suggestions inserts the `$skill-name` tag instead of the file path ([#420](https://github.com/pbi-agent/pbi-agent/pull/420)).

## Changed

- While dictating, the composer shows a pulsing dot, the elapsed time, and a scrolling loudness timeline instead of the row of red bars ([#422](https://github.com/pbi-agent/pbi-agent/pull/422)).
- Composer tags render as bordered pills, and skill tags are violet in both the composer and sent messages ([#420](https://github.com/pbi-agent/pbi-agent/pull/420)).

## Fixed

- Unsent composer text is no longer lost when opening or closing the files, tasks, or terminal panel, or when switching sessions ([#421](https://github.com/pbi-agent/pbi-agent/pull/421)).

## Documentation

- The speech-to-text guide covers the on-device model: download size, platforms, languages, speed, and memory use ([#422](https://github.com/pbi-agent/pbi-agent/pull/422)).
