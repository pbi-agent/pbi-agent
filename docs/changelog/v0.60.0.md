# v0.60.0

**Release date:** 2026-11-13

## Added

- The agent and sub-agent system prompts now end with a short `<system_info>` section giving the current date, the operating system, and the shell the `shell` tool runs commands with, so the model picks commands and dates that fit your machine ([#426](https://github.com/pbi-agent/pbi-agent/pull/426)).

## Fixed

- Enabling local speech-to-text on Windows no longer fails with `WinError 5` (access denied) while installing the speech engine. When antivirus or the search indexer is still scanning the freshly unpacked files, the install now copies them into place instead of renaming the folder. The same fix covers the on-device session-title model ([#427](https://github.com/pbi-agent/pbi-agent/pull/427)).
