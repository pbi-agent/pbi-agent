# v0.52.0

**Release date:** 2026-11-12

## Added

- The web UI has an interactive terminal panel, and shell code snippets in replies get a Run button that sends them to the terminal ([#399](https://github.com/pbi-agent/pbi-agent/pull/399)).
- A new `/status` dialog in the web UI reports session token usage, cost, cache, context, sub-agent, and activity metrics ([#392](https://github.com/pbi-agent/pbi-agent/pull/392)).
- The `ask_user` panel accepts freeform answers alongside suggested options, with 1-3 number shortcuts, and is now available on chat-completions profiles ([#389](https://github.com/pbi-agent/pbi-agent/pull/389)).
- The sidebar New button shows a "New session" tooltip with its `Ctrl+Shift+O` shortcut ([#391](https://github.com/pbi-agent/pbi-agent/pull/391)).

## Changed

- `pbi-agent run` now uses the same session channel as the web UI, so CLI sessions open in the web UI with the same timeline ([#396](https://github.com/pbi-agent/pbi-agent/pull/396)).
- `pbi-agent init` and `/init` now only create the starter `AGENTS.md`; they no longer install default commands and sub-agents ([#388](https://github.com/pbi-agent/pbi-agent/pull/388)).
- Raw-output notices reference the saved output path instead of repeating it, and background task completions show the path as a separate field ([#394](https://github.com/pbi-agent/pbi-agent/pull/394)).
- The background tasks toggle uses a layers icon so it no longer reads as a metrics control ([#400](https://github.com/pbi-agent/pbi-agent/pull/400)).

## Fixed

- Interrupting a turn while a sub-agent runs now stops the session cleanly, re-enables the composer, and removes the interrupted turn's intermediate output ([#390](https://github.com/pbi-agent/pbi-agent/pull/390)).
- Long model names in the CLI welcome header wrap instead of being clipped ([#395](https://github.com/pbi-agent/pbi-agent/pull/395)).
- The copy shortcut no longer overlaps the code block header ([#397](https://github.com/pbi-agent/pbi-agent/pull/397)).
- Text in meta badges is vertically centered ([#398](https://github.com/pbi-agent/pbi-agent/pull/398)).
- Keyboard shortcut text in tooltips is visible again ([#391](https://github.com/pbi-agent/pbi-agent/pull/391)).
