# v0.47.0

**Release date:** 2026-11-07

## Added

- New `background_task` tool lists, inspects, reads output from, and kills background tasks, separate from `shell` ([#373](https://github.com/pbi-agent/pbi-agent/pull/373)).
- `sub_agent` now takes a required intent label shown in the UI and supports `run_in_background`; the background tasks panel links to the sub-agent session ([#374](https://github.com/pbi-agent/pbi-agent/pull/374)).
- Images read by tools now appear in the session timeline as a gallery with a lightbox ([#375](https://github.com/pbi-agent/pbi-agent/pull/375)).

## Changed

- `explore_workspace` can now access paths outside the workspace ([#376](https://github.com/pbi-agent/pbi-agent/pull/376)).
- Refreshed web UI layout and styling ([#371](https://github.com/pbi-agent/pbi-agent/pull/371)).

## Fixed

- SSE streams now shut down gracefully when the server stops ([#372](https://github.com/pbi-agent/pbi-agent/pull/372)).
- Cancellation propagates to nested sub-agents, and oversized background output keeps its tail ([#374](https://github.com/pbi-agent/pbi-agent/pull/374)).
