# v0.64.0

**Release date:** 2026-11-18

## Added

- Added pricing for GPT-6.2 Astra and GPT-6.2 Sol so usage and cost tracking cover the new models ([#439](https://github.com/pbi-agent/pbi-agent/pull/439)).

## Changed

- The ChatGPT backend now identifies as Codex client 0.170.0 for requests and model discovery ([#438](https://github.com/pbi-agent/pbi-agent/pull/438)).

## Fixed

- Chat Completions responses blocked by a content filter now show a clear error with refusal text, partial output, and filter categories instead of an empty reply, for generic, GCP, and GitHub Copilot providers; reported token usage is still counted ([#440](https://github.com/pbi-agent/pbi-agent/pull/440)).
