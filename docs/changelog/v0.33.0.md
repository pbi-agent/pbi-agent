# v0.33.0

**Release date:** 2026-09-12

## Changed

- Shortened `explore_workspace` tool descriptions and clarified when to use partial-filename search versus exact-path listing ([03b51958](https://github.com/pbi-agent/pbi-agent/commit/03b5195862a66a20e36dc0e7e90b5d50ce72bb60)).

## Fixed

- Recover missing `explore_workspace` list targets that look like filenames with a literal basename search under the same root. Return candidate paths, a recovery notice, and search continuation without reading files; preserve exact listings, filters, ignores, validation errors, and workspace confinement ([03b51958](https://github.com/pbi-agent/pbi-agent/commit/03b5195862a66a20e36dc0e7e90b5d50ce72bb60)).
- Replay full ChatGPT conversation and active-turn context on the first request after releasing the parent socket for a sub-agent, rather than first attempting a stale response ID. Preserve reasoning and completed tool results without rerunning tools, then resume normal continuation ([1a9376b0](https://github.com/pbi-agent/pbi-agent/commit/1a9376b033229f362329845d71b8c37b42ae923a)).

## Internal

- Persist tool recovery metadata in run traces, separately from display metadata, including the requested/effective operation and pagination details ([03b51958](https://github.com/pbi-agent/pbi-agent/commit/03b5195862a66a20e36dc0e7e90b5d50ce72bb60)).
