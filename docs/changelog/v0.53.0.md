# v0.53.0

**Release date:** 2026-11-12

## Added

- Sessions get short, descriptive titles generated locally by a small downloaded model, in both the web UI and `pbi-agent run`; manual renames are kept ([#402](https://github.com/pbi-agent/pbi-agent/pull/402)).

## Fixed

- The chat composer stays anchored at the bottom when opening the files, tasks, or terminal side panels ([#403](https://github.com/pbi-agent/pbi-agent/pull/403)).
- Follow-up delivery menu items and tool-card meta badges are vertically centered ([#405](https://github.com/pbi-agent/pbi-agent/pull/405), [#406](https://github.com/pbi-agent/pbi-agent/pull/406)).

## Internal

- The release workflow strips VitePress frontmatter from changelog pages before publishing GitHub Release notes and validates the notes format; its tests now cover the changelog gate ([#404](https://github.com/pbi-agent/pbi-agent/pull/404)).
