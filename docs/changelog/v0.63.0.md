# v0.63.0

**Release date:** 2026-11-13

## Added

- The Run Detail trace now shows input and output token usage for each model call and agent run, with a tooltip for exact input, cached, output, and reasoning counts ([#435](https://github.com/pbi-agent/pbi-agent/pull/435)).

## Changed

- Refreshed OpenAI and Claude model pricing, adding new GPT-6.x, GPT-5.6, Claude Fable/Mythos 5.2, Sonnet 5.5, and Haiku 5.5 rates; dotted Claude model IDs now resolve to the same pricing as hyphenated IDs ([#434](https://github.com/pbi-agent/pbi-agent/pull/434)).
