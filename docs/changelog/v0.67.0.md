# v0.67.0

**Release date:** 2026-11-28

## Added

- Background tasks now work in `pbi-agent run`, board and channel tasks, and sub-agents: results arrive at the next tool step, and a run whose model ends its turn while tasks are running waits and wakes it with the result ([#461](https://github.com/pbi-agent/pbi-agent/pull/461)).
- The shell tool accepts `tty: true` to run a command under a pseudo-terminal (POSIX only), and `background_task` gains an `input` action to type into a running task, such as a REPL, including Ctrl-C and Ctrl-D ([#461](https://github.com/pbi-agent/pbi-agent/pull/461)).

## Changed

- Breaking: the shell `timeout_ms` parameter is replaced by `yield_time_ms` (default 30 s, max 5 min); a command still running at that point moves to a background task with its output so far instead of being killed, and foreground commands no longer get stdin, so prompts fail fast instead of hanging ([#461](https://github.com/pbi-agent/pbi-agent/pull/461)).
- Breaking: tool results reach the model as compact plain text instead of a JSON envelope, for every provider; `PostToolUse` hooks now receive that text in `tool_response` and the structured result in a new `tool_result` field ([#461](https://github.com/pbi-agent/pbi-agent/pull/461)).
- Auto-compaction now triggers at 90% of the active model's context window when `compact_threshold` is unset, instead of a fixed 200k tokens ([#461](https://github.com/pbi-agent/pbi-agent/pull/461)).
- Background task output reads return only output the model has not seen yet, and background result headers no longer repeat the task id, saving tokens on every result ([#461](https://github.com/pbi-agent/pbi-agent/pull/461), [#462](https://github.com/pbi-agent/pbi-agent/pull/462)).

## Fixed

- GPT models on OpenAI, ChatGPT, and Copilot Responses no longer fill every optional tool parameter with invented values; function tools are now sent with `strict: false` ([#463](https://github.com/pbi-agent/pbi-agent/pull/463)).
- The ChatGPT Codex backend now caches the system prompt across calls, cutting uncached input tokens; it is sent as the first developer input item, with `session-id` and `thread-id` headers ([#464](https://github.com/pbi-agent/pbi-agent/pull/464)).
