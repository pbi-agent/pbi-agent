# v0.42.0

**Release date:** 2026-11-06

## Added

- Run long shell commands in the background from web sessions: the agent can start, inspect, and kill background tasks, results wake or steer the session automatically, and a new Background tasks side panel shows live status and output ([#361](https://github.com/pbi-agent/pbi-agent/pull/361)).
- Reply to a selection: select text in an assistant message, add a comment, and attach it to your next message as a quoted reply snippet ([#362](https://github.com/pbi-agent/pbi-agent/pull/362)).

## Fixed

- Long shell commands no longer overflow the Background tasks panel: cards truncate the command, and expanding a card shows the full input and output in scrollable areas ([#364](https://github.com/pbi-agent/pbi-agent/pull/364)).

## Internal

- CI now uses Bun 1.4.4 and builds the web bundle under the Bun runtime, so the committed static assets are verified reproducibly ([#365](https://github.com/pbi-agent/pbi-agent/pull/365)).

## Documentation

- Remove an unused `model_profile_id` reference from the review mode documentation ([#361](https://github.com/pbi-agent/pbi-agent/pull/361)).
