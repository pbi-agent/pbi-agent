# v0.38.0

**Release date:** 2026-09-28

## Added

- Add `pbi-agent upgrade` (alias `update`) to upgrade to the latest PyPI release. It detects how pbi-agent was installed and runs `uv tool upgrade`, `pipx upgrade`, or virtual-environment `pip`, refuses source installs, and verifies the installed version afterwards. On Windows the installer runs after pbi-agent exits. `--check` reports status only and exits `0` when up to date, `100` when an update is available, or `1` on error ([db3790c7](https://github.com/pbi-agent/pbi-agent/commit/db3790c7cf564650db89acd834a1562fa0839a4a)).

## Changed

- The startup update notice now suggests the upgrade command that matches your install method ([db3790c7](https://github.com/pbi-agent/pbi-agent/commit/db3790c7cf564650db89acd834a1562fa0839a4a)).

## Documentation

- Document `pbi-agent upgrade` in the CLI reference and installation guide ([db3790c7](https://github.com/pbi-agent/pbi-agent/commit/db3790c7cf564650db89acd834a1562fa0839a4a)).
