# v0.35.0

**Release date:** 2026-09-24

## Added

- Add input, output, and cache pricing for ten missing Claude models: Fable 5.1, Mythos 5.1, Opus 5.5, Opus 5, Opus 4.5, Opus 4.1, Opus 4, Sonnet 4.5, Sonnet 4, and Haiku 3.5. Recognize dotted and hyphenated version aliases for Fable 5.1, Mythos 5.1, and Opus 5.5, including their discounted cache-hit rates ([eef1cecf](https://github.com/pbi-agent/pbi-agent/commit/eef1cecf9d596db90ed6afbd27e803606fe87559)).

## Fixed

- Correct Claude Sonnet 5 cost estimates to the standard $2 input and $10 output per million tokens, with $2.50 five-minute cache writes, $4 one-hour cache writes, and $0.20 cache hits ([eef1cecf](https://github.com/pbi-agent/pbi-agent/commit/eef1cecf9d596db90ed6afbd27e803606fe87559)).
