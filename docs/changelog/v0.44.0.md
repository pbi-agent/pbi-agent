# v0.44.0

**Release date:** 2026-11-06

## Changed

- Updated runtime dependencies to their latest releases, including MCP 2.3, FastAPI 0.162, Rich 15, and Uvicorn 0.54; MCP HTTP connections now follow the MCP 2.x client API, and timed-out MCP tool calls notify the server with a cancellation ([8797827](https://github.com/pbi-agent/pbi-agent/commit/87978274)).

## Fixed

- Fixed a race in web session input-state publishing where follow-up input could be re-enabled or published out of order around turn end, which also made follow-up tests flaky.

## Internal

- Updated development tooling to Ruff 0.17 (legacy lint rule set kept, Markdown formatting enabled), basedpyright 1.40, pytest 9.2, and HTTPX2 2.16, and regenerated `uv.lock` ([8797827](https://github.com/pbi-agent/pbi-agent/commit/87978274)).
