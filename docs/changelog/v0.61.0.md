# v0.61.0

**Release date:** 2026-11-13

## Added

- `pbi-agent run` and `pbi-agent sandbox run` accept `-p` as a short alias for `--prompt` ([#429](https://github.com/pbi-agent/pbi-agent/pull/429)).
- New `--show-steps` flag for `pbi-agent run` and `pbi-agent sandbox run` displays every intermediate step: the welcome panel, thinking, tool calls, sub-agents, and usage ([#429](https://github.com/pbi-agent/pbi-agent/pull/429)).

## Changed

- `pbi-agent run` now prints only the final assistant response, followed by `session_id=...`, so its output is easy to read and to use in scripts. Errors still go to stderr. Pass `--show-steps` to get the previous full output ([#429](https://github.com/pbi-agent/pbi-agent/pull/429)).
