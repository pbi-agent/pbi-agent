# v0.51.0

**Release date:** 2026-11-10

## Added

- New `read_image` tool attaches PNG, JPEG, WEBP, HEIC, and HEIF images from workspace-relative or absolute paths, with the 20 MB limit checked before reading ([#384](https://github.com/pbi-agent/pbi-agent/pull/384)).
- When shell output is truncated or lossily compressed, the full raw output is saved under `~/.pbi-agent/shell-output/` and the tool result points to it; files older than 24 hours are cleaned up at startup ([#385](https://github.com/pbi-agent/pbi-agent/pull/385)).

## Changed

- The `read` tool group is renamed to `read-image`; `read` and `read_image` remain accepted as aliases in profiles, `--allowed-tools`, and command or sub-agent frontmatter ([#384](https://github.com/pbi-agent/pbi-agent/pull/384)).
- Skills now load `SKILL.md` through `shell`, and a warning is shown when skills are configured without `shell` ([#384](https://github.com/pbi-agent/pbi-agent/pull/384)).

## Fixed

- The web session page no longer polls the full workspace file tree every 2 seconds while the explorer is closed; the tree refreshes right after agent file edits instead ([#386](https://github.com/pbi-agent/pbi-agent/pull/386)).

## Removed

- The `explore_workspace` tool and its `codetool-explore` dependency are removed; the agent reads and searches files through `shell` ([#384](https://github.com/pbi-agent/pbi-agent/pull/384)).
