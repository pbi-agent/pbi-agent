# v0.55.0

**Release date:** 2026-11-12

## Changed

- Smaller install: pbi-agent now depends on plain `uvicorn` plus `websockets` instead of `uvicorn[standard]`, dropping PyYAML, uvloop, httptools, and watchfiles (about 25 MB to 2 MB) ([#410](https://github.com/pbi-agent/pbi-agent/pull/410)).

## Fixed

- Python 3.15 is supported again: with PyYAML gone, no dependency needs a C++ compiler on Windows, so the `<3.15` cap from v0.54.0 is removed ([#410](https://github.com/pbi-agent/pbi-agent/pull/410)).
