# v0.46.0

**Release date:** 2026-11-07

## Changed

- Injected workspace `MEMORY.md` is now capped at 200 lines / 25 KB with a truncation note, for both main agents and sub-agents ([#369](https://github.com/pbi-agent/pbi-agent/pull/369)).
- The `pbi-agent init` `AGENTS.md` template now uses purpose-based memory guidance: a short `MEMORY.md` index plus `.agents/memory/<topic>.md` pages, verification tags, main-agent-only writes, and read-only past-session lookup ([#369](https://github.com/pbi-agent/pbi-agent/pull/369)).

## Internal

- Restructured project memory into an index plus topic pages and aligned the `compress` skill ([#369](https://github.com/pbi-agent/pbi-agent/pull/369)).
