# v0.66.0

**Release date:** 2026-11-20

## Added

- Every `pbi-agent` command and subcommand now accepts `--doc`, which prints a Markdown usage guide with options, examples, and pitfalls so you and your agents can learn the CLI from the terminal ([#451](https://github.com/pbi-agent/pbi-agent/pull/451)).
- File links in the session timeline open the file in the Explorer preview without leaving the session; `path:42`, `path:42-50`, and `#L42` targets jump to and highlight those lines ([#445](https://github.com/pbi-agent/pbi-agent/pull/445)).
- Web chat agents now know that `bash` blocks get a Run button and file links open in the in-app preview, so they reply with runnable commands and clickable file references ([#446](https://github.com/pbi-agent/pbi-agent/pull/446)).

## Changed

- The Add Skill, Add Command, and Add Agent dialogs stay open after an install so you can install several items from one listing; installed items show an Installed badge with a Replace option ([#448](https://github.com/pbi-agent/pbi-agent/pull/448)).
- External HTTP(S) links in rendered Markdown open in a new tab ([#445](https://github.com/pbi-agent/pbi-agent/pull/445)).
- The built-in system prompt and tool usage text are shorter with the same rules, using fewer tokens per request ([#447](https://github.com/pbi-agent/pbi-agent/pull/447)).

## Fixed

- Enhance prompt no longer fails with a 400 error on GitHub Copilot; requests without tools (prompt enhancement, compaction) no longer send tool fields on any provider ([#456](https://github.com/pbi-agent/pbi-agent/pull/456)).
- Wide Markdown tables scroll sideways inside their own area instead of overflowing the message card and the timeline ([#453](https://github.com/pbi-agent/pbi-agent/pull/453)).

## Internal

- Added the `/factory` project workflow and tightened its stage instructions, verification order, and post-release records ([#452](https://github.com/pbi-agent/pbi-agent/pull/452), [#454](https://github.com/pbi-agent/pbi-agent/pull/454), [#457](https://github.com/pbi-agent/pbi-agent/pull/457)).
