# v0.40.0

**Release date:** 2026-09-30

## Changed

- Upgrade MCP to `1.28.1`, development HTTPX2/httpcore2 to `2.12.0`, and Vitest/coverage to `4.1.11`; refresh locked dependencies, including AnyIO `4.15.1`, cryptography `50.0.2`, and PyJWT `2.15.1`, to address known dependency advisories ([10cbecc8](https://github.com/pbi-agent/pbi-agent/commit/10cbecc86e3f8130ed6891729c628605f1e3935a)).

## Fixed

- Restore MCP HTTP connections with custom headers using the supported SDK client API. Isolate connection lifetimes so disconnects, timeouts, and cleanup do not disrupt other servers or hang shutdown ([10cbecc8](https://github.com/pbi-agent/pbi-agent/commit/10cbecc86e3f8130ed6891729c628605f1e3935a)).

## Internal

- Expand MCP regression coverage with real-SDK HTTP and stdio tests for authentication, multi-server isolation, failures, timeouts, cleanup, and process exit; update frontend test mocks for Vitest 4 ([10cbecc8](https://github.com/pbi-agent/pbi-agent/commit/10cbecc86e3f8130ed6891729c628605f1e3935a)).
