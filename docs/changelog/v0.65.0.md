# v0.65.0

**Release date:** 2026-11-18

## Fixed

- `pbi-agent upgrade` on Windows no longer looks hung: the deferred installer now runs in its own console window, so your shell prompt returns right away; the window closes after a successful upgrade and stays open on failure ([#442](https://github.com/pbi-agent/pbi-agent/pull/442)).
- The Windows deferred upgrade now reports failure when the installer is missing or the installed version did not change, and only pauses for input in interactive sessions so scheduled tasks and CI never block ([#443](https://github.com/pbi-agent/pbi-agent/pull/443)).
